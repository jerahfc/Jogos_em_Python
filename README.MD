# 🐍 🎮 Jogos em Python 👾 🐍

Repositório dedicado ao desenvolvimento de jogos em Python, reunindo projetos que exploram lógica de programação, interfaces gráficas e mecânicas de jogo — do terminal ao visual.

## 🎯 Objetivo

Desenvolver jogos funcionais aplicando conceitos de programação como estruturas de dados, orientação a objetos, controle de fluxo e manipulação de eventos — consolidando o aprendizado de Python de forma prática e progressiva.
